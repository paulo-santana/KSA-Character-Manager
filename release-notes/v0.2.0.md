**Fixed crew:** a character mod can now name crew that every new game starts with, the way the game always starts with Hunter, Banjo and Polaris. With [KSP Characters](https://github.com/paulo-santana/KSA-KSP-Characters) 0.5.0 or later, that's Jebediah, Bill, Bob and Valentina Kerman.

- They join a new game's roster right after Hunter, Banjo and Polaris, each in place of a random recruit, so the roster keeps its size.
- Only while their mod is ticked under Roster Character Models.
- In a Testing start, the game seats the first two in the starting vehicles: Jeb and Bill.
- "Regenerate unused recruits" leaves them alone, like the game's three.
- Saves that already exist are not changed.

For mod authors: add `[[crew]]` entries (`name`, `character`) to your `characters.toml`; see the README.
