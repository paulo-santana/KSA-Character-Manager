**Fixes the crash of 0.5.0 on KSA 2026.11.16.5901 and later.**

- **0.5.0 crashed the game on 2026.11.16.5901 and later** (seen on 2026.11.25.5949) as soon as a Kerbal sat in a seat: `Method not found: AnimatedRenderable.SetAnimation(IAnimation, Single)`. The release was built against the game files of 2026.11.10.5801, where `SetAnimation` has two parameters; the newer builds have a third. This version is built against 2026.11.25.5949, so it runs on 2026.11.16.5901 and later, and no longer on 5801.
- Nothing else changes from 0.5.0.
